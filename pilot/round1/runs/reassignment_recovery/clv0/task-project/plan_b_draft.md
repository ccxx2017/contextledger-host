## 二、目标与非目标

**目标**：新建数据层 `data.py`，以纯函数 + numpy 向量化实现价格数据的加载、清洗、对齐、规范化，为回测层提供可靠输入。

**非目标**：
- 不修改 `backtest.py` 及其测试（冻结面零触碰）
- 不引入新第三方依赖（仅标准库 + numpy）
- 不做实时数据接入/网络 IO（若需要，属后续独立方案）

## 三、范围定义（待会上确认）

`data.py` 职责清单：

| 职责 | 内容 |
| --- | --- |
| 加载 | 从 CSV / 可迭代序列读取价格数据为 `numpy.ndarray` |
| 清洗 | 缺失值（NaN/空行）策略、异常值标记（不静默丢弃） |
| 对齐 | 多序列按索引对齐、重复索引检测 |
| 规范化 | 去量纲（如首价归一）、dtype 统一为 float64 |

## 四、技术设计要点

- 全部纯函数、无副作用，便于差分对拍（沿用方案 A 期间固化的"纯 Python 参照实现 vs 向量化实现"测试模式）
- 清洗策略显式化：NaN 与 `backtest` 现行口径衔接（NaN 按"不大于"处理）需在文档中显式声明，由数据层保证输入语义，回测层不改
- 每个函数可独立基准测试（沿用 `benchmark_backtest.py` 模式新增 `benchmark_data.py`）
