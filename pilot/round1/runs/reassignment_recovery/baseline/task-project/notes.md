# 回测模块改造笔记

## 方案 A：向量化 + 结果缓存（已完成）

### 范围确认
- 保持 `run_backtest(prices) -> dict` 签名与返回语义不变（含基线怪癖：`trades` 为期末持仓数；残留持仓按末日价格估值；空序列返回 `{"final_value": 10000.0, "trades": 0}`）。
- 消除逐日 Python 循环，改为 numpy 数组运算。
- 同一价格序列重复回测走结果缓存。

### 实现（backtest.py）
- 向量化：
  - `is_buy = np.diff(p) > 0`：第 t 天价格高于前一天即买入 1 单位（与基线一致）。
  - `c = [0, cumsum(is_buy)]`：c[t] 为截至第 t 天的累计买入数。
  - 现金流出 = 非买入日掩码对 `p[1:]` 求和；买入成本 `p[1:][is_buy].sum()`。
  - 卖出日 = 全部非买入日（持仓为 0 的空转日贡献自然为 0），持仓 = 当日累计买入数减上一个非买入日的累计买入数（前向差分），现金流 `p[nb_days] * pos` 求和。
  - 期末持仓 = `c[-1] - 最后一个非买入日的 c`，按 `p[-1]` 估值。
- 缓存：
  - `run_backtest` 仅做 `tuple(prices)` 入参规范化，核心在 `_run_backtest_cached`（`@lru_cache(maxsize=256)`）。
  - 返回 dict 的浅拷贝，防止调用方污染缓存对象。

### 决策记录（lead 确认前按默认值推进，可推翻）
- 浮点容差：接受容差等价（rel=1e-12 量级），不要求位级一致。
- 测试加固：已纳入本轮（test_backtest.py 从 3 项扩至 11 项）。
- 缓存参数：维持 `maxsize=256`，不暴露配置项。

### 验证
- `pytest test_backtest.py -v`：11 passed。
- 用例覆盖：空/单元素/单边涨/单边跌/全平/平仓后回升（平价触发卖出）/list 与 tuple 同键命中/203 组随机序列等价对拍（trades 精确一致 + final_value 容差断言）/缓存命中断言/返回 dict 隔离性。
- 等价性对拍（离线 5003 组大样本）：与基线循环实现逐一对比——
  - `trades` 100% 一致（0 分歧）。
  - `final_value` 最大绝对差 1.27e-11，最大相对差 1.4e-15（机器精度级），来源为 numpy 配对求和与基线顺序累加的浮点结合顺序差异，非逻辑分歧。
- 性能抽样：20 万点序列首次计算 ~16ms（含建键），缓存命中 ~7ms（开销主要来自 `tuple()` 建键，精确匹配缓存的必要成本）。

### 已知边界 / 注意事项
- 缓存按完整序列精确匹配（含浮点值相等语义，`1 == 1.0` 视为同键），不缓存近似序列。
- `maxsize=256`：重复序列集较大时可调大或改 `maxsize=None`。
- 建键为 O(n)（tuple 化 + 哈希），对超长序列缓存收益 = 省去计算部分，非全程 O(1)。
