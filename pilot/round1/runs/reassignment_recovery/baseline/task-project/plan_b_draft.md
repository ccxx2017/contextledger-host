## 3. 技术方案
### 3.1 依赖选型
- 主选：纯 numpy（2.0.2 已就绪）；pandas（2.3.3 已装）仅在 D3 批准后限用于 `read_csv` 解析。
- 理由：单序列场景 numpy 足够，依赖更轻，行为更可控。

### 3.2 模块边界与接口（草案 API）
```
load_prices(source)        -> np.ndarray   # ① 内存序列 ② CSV 文件（视 D1）
clean_prices(arr, policy)  -> np.ndarray   # 缺失/非有限值处理（视 D4）
align_prices(arr, keys)    -> np.ndarray   # 去重/排序/对齐（仅当源含时间戳）
to_sequence(arr)           -> list[float]  # 衔接冻结接口的出口
```

### 3.3 向量化要点
- 掩码过滤替代逐元素循环；`np.isfinite` 识别脏值；`np.interp` 可选填充；`argsort/unique` 做对齐去重。
- 验收红线：数据通路中不允许出现 Python 级 `for`。

### 3.4 正确性基准
- 先写逐元素 loop 参考实现作 oracle，与向量化实现差分对拍，容差 1e-12（沿用方案 A 口径）。

### 3.5 性能基准
- 参照系：方案 A 实测口径（20 万点首算 ~16ms）。
- 正式目标规模与阈值见 D2；测量口径：首算 / 重复 两种。
