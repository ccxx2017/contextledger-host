## 方案 A：向量化 + 结果缓存（已完成）

### 范围
- `run_backtest` 逐 bar Python 循环 → numpy 向量化；语义与基线逐点一致：
  连续上涨步逐 bar 买入 1 单位（按当根价成交），任一非上涨步且持仓 > 0 时
  全仓清仓，期末持仓按最后一根价估值；`trades` 保持基线语义 = 期末剩余持仓。
- 新增结果缓存：相同价格序列（tuple 归一化 key）重复回测命中 `lru_cache(maxsize=256)`。
- 对外 API 不变：`run_backtest(prices) -> {"final_value", "trades"}`。
- 浮点契约：向量化采用 numpy 成对求和，与基线顺序求和允许最后一位 ulp 级
  差异，判据为相对误差 ≤ 1e-9（见"遗留/注意"与 fuzz 判据）。

### 实现要点
- `up = np.diff(p) > 0` 在 diff 空间标记买入信号，**注意 `up[j]` 对应价格 bar j+1**
  （首版曾把 `flatnonzero(up)` 当价格 bar 索引用导致整体错位，已由等价性校验抓出）。
- 买入 bar 按"连续上涨段"分段（`np.diff(buys) != 1` 找段边界）：
  买入成本 = `p[buys+1].sum()`；段末未到最后一根 bar 的，按 `p[段末+2]` 整段清仓；
  到达末尾的段按 `p[-1]` 估值。持仓不跨段（每段先清仓再可能重开）。
- 缓存 key 用 `tuple(prices)`（C 级转换 + `int == float` 哈希一致）；命中时
  `run_backtest` 每次返回新建 dict，避免调用方改动污染缓存。
- 空序列/单元素/无上涨序列均返回 `(10000.0, 0)`，与基线一致。
