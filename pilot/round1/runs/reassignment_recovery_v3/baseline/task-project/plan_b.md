## 2. 目标 / 非目标
**目标**
1. 数据层热点路径向量化，消除逐标的/逐 bar Python 循环
2. 数据按"标的 × 时间"矩阵化组织，支持批量供给回测/因子计算
3. 引入按数据版本（而非按值）的缓存 key——直接回应方案 A 遗留项
   （长序列按值 key 归一化 O(n)，无法 O(1) 命中）

**非目标**
- 不改回测策略语义与回测实现
- 不引入新存储组件/数据库（如需另立方案）

## 3. 技术方案（框架级，待数据层定位后细化）
- **矩阵化**：多标的收盘价统一为 `(T × N)` float 矩阵，缺失值显式策略
  （前值填充/剔除/掩码，三选一需拍板）
- **对齐**：交易日历统一对齐，避免隐式 reindex 造成的静默错位
- **复权/清洗向量化**：复权因子按列广播；异常值规则向量化判定
- **数据版本缓存**：`key = (数据集版本, 标的集 hash, 区间)`，命中 O(1)
- **供给接口**：向下游输出仍兼容 `Sequence[float]` / ndarray 两种形态
