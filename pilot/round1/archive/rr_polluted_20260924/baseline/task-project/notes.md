## 3. 实现要点（backtest.py）
向量化：
- `is_buy = np.diff(p) > 0`：第 t 天价格高于前一天即买入 1 单位（与基线一致）。
- `c = [0, cumsum(is_buy)]`：c[t] 为截至第 t 天的累计买入数。
- 买入成本 = `p[1:][is_buy].sum()`。
- 卖出日 = 全部非买入日（持仓为 0 的空转日贡献自然为 0）；当日持仓 = 当日累计买入数 − 上一个非买入日累计买入数（前向差分）；卖出现金流 = `p[nb_days] * pos` 求和。
- 期末持仓 = `c[-1] − 最后一个非买入日的 c`，按 `p[-1]` 估值。

缓存：
- `run_backtest` 仅做 `tuple(prices)` 入参规范化，核心在 `_run_backtest_cached`（`@lru_cache(maxsize=256)`）。
- 返回 dict 浅拷贝，防止调用方污染缓存对象。

  - `final_value` 最大绝对差 1.27e-11，最大相对差 1.4e-15（机器精度级），来源为 numpy 配对求和与基线顺序累加的结合顺序差异，非逻辑分歧。

## 6. 已知边界 / 注意事项
- 缓存按完整序列精确匹配（浮点值相等语义，`1 == 1.0` 视为同键），不命中近似序列。
- `maxsize=256`：重复序列集较大时可调大或改 `maxsize=None`。
- 建键为 O(n)（tuple 化 + 哈希），超长序列的缓存收益 = 省去计算部分，非全程 O(1)。
- 价格含 NaN 不在处理范围内（语义未定义，与基线一致）。
