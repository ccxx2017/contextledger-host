# 回测模块改造笔记

## 方案 A：向量化 + 结果缓存（2026-09-24）

### 范围
- 对 `backtest.py` 的 `run_backtest` 做重构：numpy 向量化 + 相同输入的结果缓存。
- 公共 API 与策略语义不变：`run_backtest(prices) -> {"final_value": float, "trades": int}`。

### 实现要点
- **向量化**（`_backtest_vectorized`）：不做逐日现金流模拟，改为识别"连续上涨段（run）"后分段聚合：
  - 买入总额 = `dot(arr[1:], up)`（每个上涨日买 1 份）；
  - 每段在段后第一个非上涨日整段卖出，卖出总额 = `dot(段尾次日价格, 段长)`；
  - 末段若延伸至最后一天则不计卖出，按末日价格估值计入 `final_value`，段长即 `trades`。
  - 基线循环保留为 `_backtest_loop`，作为等价性验证的参照实现。
- **缓存**（`_backtest_cached`）：`lru_cache(maxsize=256)`，键为 `tuple(prices)`；`run_backtest` 返回字典副本，调用方改写结果不会污染缓存。

### 踩过的坑
1. 段终点 `ends` 最初用"下一段起点 - 1"推导，隐含假设段首尾相接；段之间存在间隔时段长被算错。随机等价性测试当场抓住。改为"True 且后继为 False"直接定位段终点。
2. 首版（逐日 streak 法）功能正确但无性能优势：全数组多趟 pass 开销大；改分段聚合后核心计算压缩为 2 次点积 + 少量小数组操作。

### 验证
- 原基线测试 3 项全部保持通过；新增向量化等价性（200 组随机序列）、缓存命中、结果快照隔离共 3 项，合计 6 项全绿。
- 离线压测：3007 组用例（空序列 / 单点 / 全相等 / 单调 / 高频并列 / 随机）与基线零失配。
- 性能（10 万点序列，Python 3.9 + numpy 2.0.2）：基线循环 7.0ms → 向量化约 4.3ms（约 1.6x，其中列表→ndarray 转换占约 2.7ms，为接口固有成本）；缓存命中约 2.9ms（约 2.4x）。序列越长、重复调用越多收益越大。
- 浮点口径：numpy 点积（成对求和）与基线顺序累加存在 ulp 级差异，等价性断言采用 `rel_tol=1e-12`。

### 遗留
- 缓存以完整序列为键，超长序列命中仍需 O(n) 哈希；如需进一步优化可引入内容指纹（如 `hashlib` 分块摘要）作二级键。
